# Layout

Position, spacing and alignment carry hierarchy before a word is read.

## 1. Group with space, not lines
Space groups first, background shapes second, separator lines last and only where space alone cannot carry the structure.
The gap between distinct groups must be at least 2× the gap within one group:
- `gap-2` (8px) or `gap-3` (12px) inside a component group.
- `gap-6` (24px) or `gap-8` (32px) between groups or modules.

## 2. Keep controls distinct from content
Give interactive elements a clear affordance (subtle background, pill border, hover depth, or active tactile feedback). Don't let buttons look like passive text.

## 3. Align to shared edges
Avoid messy, staggered edges. Align headers, body copy, and CTA buttons along clear vertical and horizontal axes.

## 4. Order by importance
Reading order flows top-to-bottom, leading-to-trailing. Keep primary actions and key figures immediately discoverable without visual clutter.
