# Interface Writing

Clear and brief beats clever; consistent beats varied.

## 1. Verb-first buttons
A button label starts with a verb naming the action: "Kirim Formulir", "Daftar Sekarang", "Unduh Bukti", "Simpan Perubahan". Avoid vague labels like "Oke", "Yuk", or "Klik Disini".

## 2. Address the user directly and respectfully
In Indonesian interface copy, use formal yet warm Indonesian appropriate for an educational foundation: "Anda", "Siswa", "Wali Murid", "Silakan periksa kembali formulir Anda".

## 3. Clear errors and status messages
Error messages should clearly state what happened and how to resolve it: "NIS atau Tanggal Lahir tidak cocok. Pastikan NIS Anda sudah terdaftar di tata usaha sekolah."
